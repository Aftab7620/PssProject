# PssProject

This is a Salesforce-based Permit Application system built using OmniStudio, Apex, LWC, and Flows. The project allows users to create permit applications by selecting Account (Cinema) and Contact, entering permit details and reviewing the data before submission.

The repository includes Apex classes and triggers for handling backend logic such as inspection processing and automation, along with Lightning Web Components (LWC) used for UI enhancements. A record-triggered flow is used to automatically update fields like Status and Submission Date when a permit is created.

Overall, this project demonstrates a complete end-to-end implementation of a real-world use case using Salesforce technologies including Apex, LWC, OmniScript, Data Mapper, and Flow.
